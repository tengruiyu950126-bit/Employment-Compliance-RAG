# Employment-Compliance-RAG
This project is a domain-specific Retrieval-Augmented Generation (RAG) system designed to compare company handbook policies against the Malaysian Employment Act 1955.

The system supports:

Policy question answering
Handbook vs Employment Act comparison
Compliance analysis
Multi-turn conversational memory
Source-grounded responses
Out-of-scope query detection

The project was developed as a legal and HR-focused RAG prototype using LangChain, ChromaDB, OpenAI embeddings, and GPT-based generation.
